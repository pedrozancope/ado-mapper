Rich text: line breaks, user stories & Markdown

Paragraphs converts blank lines to paragraphs and single line breaks to <br>. User story structures “As a … I want to … so that …” into three bold-labeled paragraphs. Markdown supports # headings, **bold**, *italic*, `code`, - bullets and numbered lists. For other text it preserves paragraph breaks. HTML input is escaped, not executed. Use these modes for ADO HTML fields such as Description and Acceptance Criteria; Excel cell styling is not copied.
